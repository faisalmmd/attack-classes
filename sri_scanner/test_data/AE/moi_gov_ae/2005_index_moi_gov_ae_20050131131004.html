File Upload Hints :

  • You can use any ftp software to upload your files , you can get any one from the Internet ( freeware ) e.g. ws-ftp.
  • There is an ftp client bundled with any win95 or win98 click here for more information.
  • The default home page file name should be index.html.
  • If you have a cgi script put your script in the Directory cgi-bin.
  • If yor want to configure frontpage extension , please call the System Administrator.
  • You can upload either html files (text) or images (binary files) .

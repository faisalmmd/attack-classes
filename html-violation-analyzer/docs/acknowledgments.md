# Acknowledgments & Credits

## Original Research & Development

This enhanced HTML Violation Analyzer builds upon groundbreaking research and software development by **Florian Hantke** at the **CISPA Helmholtz Center for Information Security**.

### Academic Foundation

**Publication**: "HTML Violations and Where to Find Them: A Longitudinal Analysis of Specification Violations in HTML"  
**Conference**: IMC 2022 - Internet Measurement Conference  
**Author**: Florian Hantke  
**Institution**: CISPA Helmholtz Center for Information Security  
**Paper**: [https://swag.cispa.saarland/papers/hantke2022violations.pdf](https://swag.cispa.saarland/papers/hantke2022violations.pdf)  
**Original Repository**: [https://github.com/cispa/html-violations-analyzer](https://github.com/cispa/html-violations-analyzer)

### Research Contributions

The original work made several key contributions to web measurement research:

1. **Methodology**: Developed a systematic approach for analyzing HTML specification violations at web scale
2. **Common Crawl Integration**: Pioneered the use of Common Crawl archives for longitudinal web compliance analysis
3. **Violation Taxonomy**: Created a comprehensive categorization of HTML specification violations
4. **Empirical Findings**: Provided first large-scale measurements of HTML compliance across the web
5. **Open Source Tools**: Released the analysis framework for reproducible research

### Technical Architecture

The original system's core design principles that we've preserved and enhanced:

- **Modular Crawler System**: Extensible architecture supporting multiple data sources
- **Rule-Based Validation**: Flexible framework for defining and applying HTML validation rules
- **Database Integration**: Structured storage for large-scale analysis results
- **Multi-Processing**: Efficient parallel processing for web-scale data
- **Scientific Rigor**: Methodologically sound approach to web measurement
